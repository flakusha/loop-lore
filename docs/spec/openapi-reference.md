# OpenAPI-Driven API Reference Specification

> Promoted 2026-09-18 from STUB. Authoritative source is `src/` and AGENTS.md.

## Overview

The spec is generated by `scripts/generate-openapi.ts`, which mounts `v1Routes` plus `registerPlugins` on an in-memory Elysia app and requests `GET /api/v1/openapi/json`. At runtime the same spec is served by `versionedOpenApiPlugin` (`src/routes/v1/openapi.ts`, mounted via `src/routes/v1/admin-surface.ts`). The generated spec lives at `docs/reference/openapi.json` (gitignored) and drives the rendered `docs/reference/api.md` plus any external OpenAPI tooling. `api.md` carries a DO-NOT-EDIT banner and a delimited `api-reference:handwritten` region for maintainer prose; everything else is regenerated.

## Scope

- Routes from `src/routes/` are auto-discovered.
- Schemas from `src/validation/schemas/` are emitted as TypeBox JSON Schema.
- Regeneration: `bun run openapi && bun run openapi:md` (the latter runs `scripts/generate-api-md.ts`). `docs:build` runs both so a fresh clone has a current spec on disk for the generated page and for tooling.
- Validation: the `api - doc drift` gate regenerates both artifacts and fails on a stale `api.md`, an invalid spec, or a phantom operation. `bun run schemas:check` validates the other generated schema artifacts.

## Technical Design

- **Plugin:** `versionedOpenApiPlugin` (`src/routes/v1/openapi.ts`) wraps `@elysia/openapi` and mounts the spec + Scalar UI under `/api/v1`.
- **Generation:** `scripts/generate-openapi.ts` dumps the live schema to `docs/reference/openapi.json`; `scripts/generate-api-md.ts` renders `api.md` from it.
- **CI gate:** `api - doc drift` regenerates both artifacts and fails on staleness; `schemas:check` covers the other generated schema artifacts.
- **Public exposure:** `GET /api/v1/openapi/json` serves the schema; `/api/v1/openapi` serves the Scalar UI.

## Integration Points

- `src/routes/v1/openapi.ts` — `versionedOpenApiPlugin` (spec + Scalar UI), mounted in `src/routes/v1/admin-surface.ts`
- `src/validation/schemas/` — TypeBox schema sources
- `scripts/generate-openapi.ts` — spec regeneration script
- `scripts/generate-api-md.ts` — markdown renderer (preserves the handwritten region)
- `docs/reference/openapi.json` — generated artifact (gitignored)
- `docs/reference/api.md` — generated reference page
