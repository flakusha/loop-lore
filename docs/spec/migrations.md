## Migration Strategy

### Version Tracking

```sql
CREATE TABLE IF NOT EXISTS _migrations (
  name TEXT PRIMARY KEY,
  applied_at TEXT NOT NULL DEFAULT (datetime('now'))
);
```

### Migration File Format

```
src/db/migrations/
├── 001_initial_schema.sql
├── 002_add_characters.sql
├── 003_add_rpg_tables.sql
└── ...
```

### Running Migrations

```bash
bun run src/db/migrate.ts          # apply pending
bun run src/db/migrate.ts --status  # show status
bun run src/db/migrate.ts --rollback # revert last
```

## PostgreSQL Migration Path

When swapping from `bun:sqlite` to PostgreSQL:

1. Export SQLite data to JSON
2. Create PG schema with Kysely dialect swap
3. Import JSON data with type mapping
4. Verify with integration tests

### Type Mappings

| SQLite | PostgreSQL |
|--------|-----------|
| INTEGER | BIGINT |
| TEXT | VARCHAR/TEXT |
| REAL | DOUBLE PRECISION |
| BLOB | BYTEA |
| BOOLEAN (0/1) | BOOLEAN |

## Rollback Procedures

- Each migration has `up` and `down` SQL
- Rollback runs `down` in reverse order
- Data-destructive rollbacks require backup first
