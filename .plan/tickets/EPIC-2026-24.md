# EPIC-2026-24: Filtering & Pagination

**Status:** Done
**Priority:** medium
**Effort:** Medium
**Summary:** A canonical pagination primitive (`parsePagination` + `jsonPaginated` + `PaginationQuery` TypeBox) is shared across 20+ list endpoints with combined per-route filters; frontend load-more pattern with honest `hasMore` prevents the original browser failure for lists past ~50 items. Honest `hasMore` preserved by the `BUG-message-search-promise-allsettled-rejection-inserts-phantom-` fix. Audit: `.tmp/audit-epic-2026-24.md`.
