## Status (2026-09-25 closeout — landed on dev via `giwt finalize`)

Two roadmap gaps above partially or fully closed:

- **Slash-command typed-token autocomplete** ✅ — new `src/frontend/alpine/slash-autocomplete.ts` mirrors the `@`-mention pattern at `chat-group.ts:100-211` (`slashTokenRe` regex + candidate filter + keyboard nav + a11y listbox); wired in `src/frontend/alpine/chat/bootstrap.ts` (line 47 import + line 59 spread into chat state) + mounted in `src/components/chat/input-area.html` (lines 144-173 dropdown + lines 187-190 keyboard/input wiring). 25 unit cases cover regex extraction, candidate filtering, Tab/Enter acceptance, Escape close, separator preservation. Reads `_commandList` from the existing `command-palette.ts` so the candidate set is always registry-driven.
- **`/image` availability gate** ✅ — `src/assistant/commands/image.ts` retains the original 28-line action-dispatch contract (join args → `action: "generate-image"` payload) and adds a 4-line availability gate: when `loadConfig().generation.providers.sd` is empty, `listCommands()` filters `/image` out (mirrors the sfx/music/video pattern from `BUG-advertised-sfx-music-video-commands-are-stubs`). Handler stays callable for legacy slash-input fallback paths. Provider-aware dispatch is owned by the existing `POST /api/generation/image` route, so no new HTTP route was added. No new test files: existing `simple-commands.test.ts` (lines 137-150) already pins the /image contract; the availability gate shares the `image.ts` module-load path.
- **`/image` backend adapter** remains Pending (acceptance criterion line 18) — owned by `epic-image-edit` + `epic-assistant-generation-extensions`. The route layer already returns 501 when no provider is configured; the slash-command dispatch path now correctly forwards prompts to that route.

Hold this epic **open** — closing the two roadmap gaps above does **not** close the parent. Remaining parent work is multi-month scope and belongs to:

- `epic-assistant-gm-flows` — quality-gating pipeline + confirmation gating + AI Director extension + pre-compiled templates injection (Phase 1 GM role + GameMasterService integration already on dev).
- `epic-assistant-generation-extensions` — Phases 2-4 (text-guided editing, supporting features, advanced features, scenario source bridging); only the `/image` availability gate + dispatch contract touched in this wedge.
- `epic-assistant-entity-access` — slash commands for RAG / asset / world / location / character / item / duplicate / adapt access; multi-batch work.
- `epic-assistant-creative-studio-workflows` — workflow engine, model-family presets, entity workflow templates, gallery batch ops; coordination hub owning its own sub-epics.

Reopen and close this epic when `epic-assistant-generation-extensions` Phase 2+ lands or a formal descope is filed.
