## Status (2026-09-25 closeout branch `epic-assistant-commands-closeout`)

Two roadmap gaps above **landed in this branch**, awaiting `giwt finalize` to land on dev:

- **Slash-command typed-token autocomplete** ✅ — new `src/frontend/alpine/slash-autocomplete.ts` mirrors the `@`-mention pattern at `chat-group.ts:79-211` (`slashTokenRe` regex + candidate filter + keyboard nav + a11y listbox); wired in `src/frontend/alpine/chat/bootstrap.ts` + mounted in `src/components/chat/input-area.html`. 25 adjacent unit cases cover regex extraction, candidate filtering, Tab/Enter acceptance, Escape close.
- **`/image` backend adapter** ✅ — new `src/assistant/image-provider.ts` resolves ComfyUI / sd-server / none from `config.generation.providers.sd` (mirroring `/translate.ts`'s `deps.complete` injection pattern); `src/assistant/commands/image.ts` carries three branches (no-provider, configured-but-unreachable, reachable) and registers `available: false` so `listCommands()` filters it out when no provider is configured (matching `BUG-advertised-sfx-music-video-commands-are-stubs`). 19 adjacent unit cases across `image.test.ts` + `image-provider.test.ts`. Existing `src/generation/image-gen-route.ts` already returns 501 when no provider is configured, so no new HTTP route was created.
- **Out-of-scope future hook**: `buildImageWorkflow(prompt, workflowTemplate, client)` in `image-provider.ts` is a stub helper reserving the `workflow_template` field from `epic-assistant-generation-extensions.md#image-generation-integration`. Wire it when `/image` accepts a `workflow_template` request parameter (Phase 2 of generation-extensions). Stub is marked with a `ponytail:` comment naming the upgrade path.

Hold this epic **open** — closing the two roadmap gaps above does **not** close the parent. Remaining parent work is multi-month scope and belongs to:

- `epic-assistant-gm-flows` — quality-gating pipeline + confirmation gating + AI Director extension + pre-compiled templates injection (Phase 1 GM role + GameMasterService integration already on dev).
- `epic-assistant-generation-extensions` — Phases 2-4 (text-guided editing, supporting features, advanced features, scenario source bridging); only Phase 1 MVP slice touched in this wedge.
- `epic-assistant-entity-access` — slash commands for RAG / asset / world / location / character / item / duplicate / adapt access; multi-batch work.
- `epic-assistant-creative-studio-workflows` — workflow engine, model-family presets, entity workflow templates, gallery batch ops; coordination hub owning its own sub-epics.

Reopen and close this epic when `epic-assistant-generation-extensions` Phase 2+ lands or a formal descope is filed.
